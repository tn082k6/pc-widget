PC-WIDGET  (iOS-18-Style, für Windows 10/11)
============================================

STARTEN
Einfach PC-Widget.exe doppelklicken. Beim ersten Start richtet sich das Widget
selbst ein (nach %LOCALAPPDATA%\PC-Widget), fragt nach deiner Stadt fürs Wetter
und startet. Danach findest du es im Startmenü unter "PC-Widget".

Falls Windows "Der Computer wurde durch Windows geschützt" zeigt:
-> "Weitere Informationen" -> "Trotzdem ausführen" (die App ist nicht signiert).

BEDIENUNG
- Immer sichtbar: Uhr, Datum und was gerade auf Spotify läuft
- Maus drüber: klappt auf -> Spotify-Lautstärke, Wetter, CPU/GPU/RAM/Festplatte
- Klick auf CPU/GPU/RAM = Task-Manager, Klick auf C: = Dieser PC
- Einstellungen: Startmenü -> PC-Widget (oder PC-Widget.exe nochmal starten)

ENTFERNEN
Einstellungen -> Apps -> Installierte Apps -> PC-Widget -> Deinstallieren.
